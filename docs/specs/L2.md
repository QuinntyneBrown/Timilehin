# L2 — Detailed Requirements

---

## L1-1: Responsive Layout System

### L2-1.1: Mobile Layout (375px)
**Traces to:** L1-1
Single-column layout with hamburger menu navigation, stacked content sections, and touch-friendly tap targets (min 44px).
**Acceptance Criteria:**
- Mobile frame is 375px wide
- Navigation collapses to hamburger icon with logo
- All content sections stack vertically
- Text is legible without zooming (min 16px body text)

### L2-1.2: Tablet Layout (768px)
**Traces to:** L1-1
Two-column grid where appropriate, with visible navigation links and balanced spacing.
**Acceptance Criteria:**
- Tablet frame is 768px wide
- Navigation shows key links inline
- Content uses 2-column grid where suitable
- Proper padding and margins for tablet reading

### L2-1.3: Desktop Layout (1440px)
**Traces to:** L1-1
Full-width layout with horizontal navigation bar, multi-column content areas, and sidebar where appropriate.
**Acceptance Criteria:**
- Desktop frame is 1440px wide
- Full horizontal navigation with all links visible
- Hero section spans full width
- Content areas use up to 3 columns where appropriate

## L1-2: Verse of the Day Module

### L2-2.1: Verse of the Day Card
**Traces to:** L1-2
A visually distinct card/section displaying the daily verse text, scripture reference, and a decorative or inspirational background/accent.
**Acceptance Criteria:**
- Verse text displayed in prominent, readable typography
- Scripture reference (e.g., "John 3:16") shown below the verse
- Visual distinction from surrounding content (card, background color, or decorative element)
- A share or copy button is visible
- Responsive across all three breakpoints

---

## L1-3: Bible Reader

### L2-3.1: Bible Navigation Interface
**Traces to:** L1-3
A book/chapter selector allowing users to navigate to any Bible book and chapter.
**Acceptance Criteria:**
- Dropdown or list for selecting a Bible book
- Chapter number selector appears after book selection
- Current selection is clearly indicated
- Works on all breakpoints

### L2-3.2: Bible Reading Pane
**Traces to:** L1-3
A clean reading area displaying verse text for the selected chapter with verse numbers, optimized for readability.
**Acceptance Criteria:**
- Verse text displayed with verse numbers
- Clean typography optimized for extended reading (serif or readable sans-serif, adequate line height)
- Scrollable content area for long chapters
- Note referencing free Bible API integration (bible-api.com)

---

## L1-4: Devotionals Section

### L2-4.1: Daily Devotional Card
**Traces to:** L1-4
A devotional entry displaying title, date, scripture reference, reflection body text, and a closing prayer prompt.
**Acceptance Criteria:**
- Devotional title and date displayed prominently
- Scripture reference linked/styled distinctly
- Reflection/body text area with comfortable reading typography
- Prayer prompt section visually separated
- Responsive across all breakpoints

### L2-4.2: Devotional Archive/List
**Traces to:** L1-4
A list or grid of past devotionals that users can browse.
**Acceptance Criteria:**
- Grid or list of devotional entries with title, date, and excerpt
- Visual hierarchy distinguishes today's devotional from past entries
- Pagination or "load more" indicator present

---

## L1-5: Homepage & Navigation

### L2-5.1: Hero Section
**Traces to:** L1-5
A visually engaging hero area at the top of the homepage with a headline, subtitle, and call-to-action button.
**Acceptance Criteria:**
- Large hero image or gradient background
- Headline text (e.g., site name / tagline)
- Call-to-action button (e.g., "Start Reading" or "Today's Devotional")
- Responsive sizing across all breakpoints

### L2-5.2: Navigation Bar
**Traces to:** L1-5
A consistent top navigation bar with links to Home, Bible Reader, Devotionals, and Verse of the Day sections.
**Acceptance Criteria:**
- Logo/brand name on the left
- Navigation links: Home, Read Bible, Devotionals, Verse of the Day
- Active state indicator for current page
- Responsive: full nav on desktop/tablet, hamburger on mobile

### L2-5.3: Homepage Content Sections
**Traces to:** L1-5
The homepage ties together featured sections: Verse of the Day, a Bible Reader teaser, and a Devotional highlight.
**Acceptance Criteria:**
- Verse of the Day section prominently placed
- Bible Reader teaser with a "Read Now" link
- Latest devotional preview with a "Read More" link
- Clear visual separation between sections
- Footer with basic links and copyright
